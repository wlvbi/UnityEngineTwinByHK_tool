# V8 发动机数字孪生 - 部件拖拽与持久化功能总结

## 📋 功能概览

本次开发为 V8 发动机数字孪生项目添加了完整的**部件拖拽系统**和**位置持久化功能**。

---

## ✨ 核心功能

### 1. 部件拖拽系统

**操作方式：**
- **左键点击拆卸的部件** → 开始拖拽（相机自动锁定）
- **拖动鼠标** → 平面移动（上下左右）
- **Ctrl + 拖动** → 深度移动（前后）
- **释放左键** → 完成拖拽（相机自动解锁）
- **ESC 键** → 取消拖拽，恢复原位

**技术特性：**
- ✅ 相机自动锁定，拖拽时视角静止
- ✅ 智能灵敏度调整（基于距离）
- ✅ 智能吸附（靠近原位 < 5cm 自动安装）
- ✅ 防止位置回弹（拖拽时暂停 Assembly 更新）
- ✅ 自动保存位置

### 2. 位置持久化系统

**自动保存：**
- 拖拽结束后自动保存到本地 JSON 文件
- 保存内容：部件 ID、自定义偏移、拆卸状态

**自动加载：**
- 场景启动时自动恢复上次的布局
- 支持跨会话保持

**一键恢复：**
- 控制面板新增"恢复默认"按钮
- 清除所有自定义位置，回到标准爆炸视图布局

## 🎮 用户操作流程

### 场景 1：自定义部件布局
```
1. 选择部件（左键点击）
2. 点击"拆下部件"按钮
3. 左键拖拽到任意位置
4. 释放左键 → 自动保存 ✅
5. 关闭程序
6. 重新打开 → 自动恢复到拖拽位置 ✅
```

### 场景 2：恢复默认布局
```
1. 点击控制面板的"恢复默认"按钮
2. 所有自定义位置清除
3. 部件回到标准爆炸位置
4. 保存文件被删除
```

### 场景 3：智能吸附安装
```
1. 拖拽部件靠近原始位置
2. 距离 < 5cm 时自动吸附
3. 部件自动安装回发动机
```

## 💾 持久化机制

### 保存位置
```
Application.persistentDataPath/EngineTwin_PartLayout.json
```

**Windows:** `C:\Users\<用户名>\AppData\LocalLow\<公司名>\<项目名>\`  
**macOS:** `~/Library/Application Support/<公司名>/<项目名>/`

### 数据格式
```json
{
  "parts": [
    {
      "partId": "oilfilter",
      "customOffset": {"x": 0.5, "y": 0.2, "z": 0.3},
      "hasCustomPosition": true,
      "isDetached": true
    }
  ],
  "version": "1.0"
}
```

## 🔧 技术实现细节

### 1. 相机锁定机制
- `EngineOrbitCamera.Lock()` - 锁定相机
- `EngineOrbitCamera.Unlock()` - 解锁相机
- 拖拽时所有相机输入被屏蔽

### 2. 位置更新暂停
- `EngineAssembly.SetDragging(part, true)` - 标记拖拽中
- `Assembly.Update()` 跳过拖拽中的部件
- 避免位置被覆盖导致回弹

### 3. 持久化流程
```
拖拽结束
    ↓
PartPositionPersistence.Save()
    ↓
遍历所有部件
    ↓
收集位置数据
    ↓
JsonUtility.ToJson()
    ↓
写入本地文件
```

### 4. 加载流程
```
场景启动
    ↓
PartPositionPersistence.Load()
    ↓
读取 JSON 文件
    ↓
JsonUtility.FromJson()
    ↓
Apply() 到各部件
    ↓
恢复拆卸状态和位置
```
