# 发动机部件拖拽系统

## 功能概述

允许用户手动拖拽已拆卸的发动机部件，并将其放置到场景中的任意位置。支持智能吸附功能，当部件靠近原始位置时自动吸附并安装。

## 操作方法

### 前置条件
1. 选中一个部件（左键点击）
2. 该部件必须已经拆卸（点击控制面板的"拆下"按钮）

### 拖拽操作
- **左键点击部件**：激活拖拽模式（相机自动锁定）
- **拖动鼠标**：在相机平行平面移动部件（上下左右）
- **Ctrl + 拖动鼠标**：沿相机深度方向移动部件（前后）
- **释放左键**：完成拖拽，保存位置（相机自动解锁）
- **ESC 键**：取消拖拽，恢复到拖拽前的位置（相机自动解锁）

### 相机锁定机制
- **拖拽时**：相机完全锁定，左键/右键/中键/滚轮都不会影响视角
- **拖拽结束**：相机自动解锁，恢复正常控制
- **好处**：避免拖拽部件时误操作相机，提供稳定的拖拽体验

### 智能吸附
当部件拖拽到距离原始位置 < 5cm 时：
- 自动吸附到原始位置
- 自动安装回发动机（状态变为"已安装"）
- 控制台显示 `[拖拽] 部件 xxx 吸附到原位并安装`

### UI 提示
拖拽时屏幕顶部会显示：
```
拖拽中: [部件名称]
拖动鼠标: 平面移动 | Ctrl+拖动: 深度移动
释放左键: 完成 | ESC: 取消
```

## 技术实现

### 核心类
- **EnginePartDragger.cs** - 拖拽系统主控制器
- **EngineAssembly.cs** - 扩展支持自定义位置存储
- **EngineOrbitCamera.cs** - 添加 Lock/Unlock 方法支持拖拽时锁定相机

### 关键特性
1. **自定义位置持久化**：拖拽后的位置会保存在 `Entry.CustomOffset`
2. **平滑过渡**：使用 EngineAssembly 的平滑系统，拖拽释放后平滑移动到目标位置
3. **世界空间拖拽**：所有拖拽操作在世界空间进行，避免父节点变换影响
4. **UI 事件过滤**：鼠标在 UI 上时不触发拖拽

### 参数配置
可以在 Inspector 中调整：
- `dragSensitivity`：平面拖拽灵敏度（默认 0.8）
- `depthSensitivity`：深度拖拽灵敏度（默认 0.01）
- `snapDistance`：吸附距离阈值（默认 0.05m = 5cm）
- `enableSnapping`：是否启用吸附功能（默认 true）

### 设计说明
- **左键直接拖拽**：拖拽时相机已锁定，无需额外按键
- **自动灵敏度调整**：根据部件与相机的距离自动调整拖拽速度，近处精细、远处快速
- **物理射线检测**：确保点击到的是目标部件本身
- **相机锁定**：拖拽期间完全锁定相机，避免误操作干扰拖拽精度
- **暂停位置更新**：拖拽时 EngineAssembly 停止更新该部件位置，避免回弹

## 使用场景

### 1. 教学演示
- 将部件拖拽到特定位置进行讲解
- 展示部件在不同角度的细节

### 2. 维修模拟
- 模拟拆卸后的部件放置在工作台
- 练习正确的拆装顺序

### 3. 自由探索
- 用户可以自由摆放部件
- 创建自定义的展示布局

## 注意事项

1. **只能拖拽已拆卸的部件**：必须先通过控制面板拆下部件
2. **选中状态**：拖拽时必须保持部件选中状态
3. **性能考虑**：拖拽使用实时物理查询，大量部件时可能影响性能
4. **爆炸视图**：拖拽的自定义位置与爆炸视图独立，爆炸视图会叠加显示
